# Android mirror: Grammar tab (target 0.5.0)

Copy SPEC.md wholesale from iOS at merge time (S7, S20-S25 and "Grammar rules data" are shared logic). This is what has to match.

## Files that must be identical in both repos
- `grammar-rules.json` (15 rules, 101 items, wave 1), byte for byte; the SHA-256 in SPEC.md is the gate. Bundled in the core module next to `irregular-verbs.json`.
- Keep `*.json -text` in `.gitattributes` on Android too, so no line-ending conversion changes the bytes.
- Item fields `fixedOrder` (boolean) and `textLang` (only `"es"`, only on `choose` items) are part of the schema: the decoder refuses anything else.

## Logic to mirror and test with the same vectors
- **Option order** (SPEC "Option order"): FNV-1a 64-bit of `<item id>#<seen>` seeds SplitMix64 (`state = seed`); Fisher-Yates from the end with `next() mod (i + 1)` (unsigned). Use unsigned 64-bit arithmetic with wrapping (Kotlin `ULong`; `Long` division and `%` are signed: do not use them). The vectors in SPEC.md are the test, including `("do-does-did-1", 0, 3)` = `[2, 0, 1]`. `answer` and `feedback` stay in file order; `fixedOrder` items are never shuffled.
- **Day**: starts at 04:00 in the device's local time zone; day number = whole days between 2001-01-01 and the local date of (instant - 4 h). Tests: local 2001-01-02 03:59 -> 0; 04:00 -> 1; 2001-01-01 02:00 -> -1 (never stored); use two time zones and a DST change.
- **Practiced**: 2 right answers on 2 different review days to 2 different items, pretest excluded, stored as `rightDays` entries `(day, item)` (at most 2). Boundary vectors: [(5,A)] no; [(5,A),(5,B)] no; [(5,A),(6,A)] no; [(5,A),(6,B)] yes. "In Review" overrides the state label.
- **Progress file** `tips.json` (schema 2): the format is each platform's own, its limits and meaning are shared: read at most 384 KB (the rules file stays 256 KB); nesting at most 8 containers; unparseable JSON, a file over the cap or another schema gives empty progress, never a crash; unknown keys and ids not in the rules are dropped; day numbers must be integers in 0...today (`due`: 0...today+31) and are dropped before any date conversion; counts and box clamped with saturating arithmetic; `rightDays` at most 2 entries with different days and items; `lastPair` kept only when it is 2 different items of that rule. Per item: `box`, `due`, `seen`, `missed`, `tryMiss`, `reviewed`. If the rules did not load, progress is not written.
- **Settings**: one optional boolean `grammarInSpanish` (absent or any other type = default: `es` when the translation language is Spanish and the interface is English, else the interface language, `en` for any other). The rule page toggle names the OTHER language ("Show in English" while Spanish is shown) and writes it; it applies to every rule, notes and feedback.
- **Search**: lower-case with `lowercase(Locale.ROOT)`, NFD and drop combining marks, split on anything that is not Unicode category L; every query word prefixes a word of title, rule lines, examples or aliases in both languages.

## Review: two separate sessions (S7 words, S25 rules)
- A session never contains both kinds. Parity test: build a words session and a rules session from the same data and assert each holds only its own kind.
- **Rules session** ("Review rules" / "Repasar reglas", lightbulb): up to 10 items = at most 5 rules x 2 items; at most 1 new rule per session (a rule is new when no item has `reviewed`); same boxes as S7 (1, 3, 7, 14, 30 days); a wrong item goes back to the first box and repeats once at least 3 cards later (inside the 10); a right answer to an item that is flagged by a Try it miss but not due keeps its box and due day and only clears the flag. `reviewed` stays on "Remove from Review" (restored by Undo), so a re-added rule is not new. A newly added item has `due = today + 1`. A rule leaves Review when every item eligible for this learner (`textLang: "es"` items only count with Spanish) has reached box 5.
- **Selection vectors** (today = day 6): rules R1 (new, 8, pos 3), R2 (new, 9, pos 1), R3 (10, pos 0), R4 (11, pos 2), R5 (12, pos 4), R6 (13, pos 5), R7 (14, pos 6) -> R1, R3, R4, R5, R6; R3 (10, pos 0) and R2 (10, pos 5) -> R3, R2; a rule with only a flagged candidate (tryMiss 3, due 10) has key 3. Items: a (due 5, pos 2), b (due 5, pos 1), c (due 9, pos 3, tryMiss 4) -> [c, b]; with lastPair {c, b} -> [c, a]; with c's tryMiss 6 and c not due -> [b, a]; plus d (due 4, pos 0, `textLang: "es"`): English-only [c, b], with Spanish [c, d]. A candidate's day is min(due, tryMiss when flagged).
- `textLang: "es"` items are candidates (and counted anywhere) only when the translation or interface language is Spanish; every rule keeps at least 3 items without it; the pretest item never has it.
- **Entry points**: Grammar tab top: one card only when a rule exercise is due ("Review rules", "4 exercises due" / "4 ejercicios para hoy", singular "1 exercise due" / "1 ejercicio para hoy", button "Review now" / "Repasar ahora"); no card when nothing is due or no rule is in Review. Words tab: the words card as it is plus, only when a rule exercise is due, one secondary row "Review rules · 4" / "Repasar reglas · 4" with a chevron. No tab badges. Large text: the card stacks, the row wraps, 44 dp targets. TalkBack: the card is one element "Review rules, 4 exercises due, button"; the session announces "Rule exercise 2 of 10".
- **End of session**: "Done for today." / "Listo por hoy."; more due now: "Done for now. N more due today." / "Por ahora, listo. Hoy quedan N más." (singular "1 more", "Hoy queda 1 más.") with "Keep going" / "Seguir"; else "N exercises tomorrow." / "Mañana tienes N ejercicios." (singular "1 exercise tomorrow." / "Mañana tienes 1 ejercicio."). The back button names where the session started ("Back to Words" or "Back to Grammar"). Use plural resources for every count.
- **Add to Review**: "“<rule>” added to Review. Starts tomorrow." / "“<regla>” agregada al Repaso. Empieza mañana." with Undo; "tomorrow" is the next review day (04:00 edge, also when added between midnight and 04:00). After adding, the button reads "Remove from Review" / "Quitar del Repaso" (Undo restores boxes and due days); "In Review" is only the row state and what the Grammar card counts. Offered once after the first round of 3 practice items (not after the pretest alone).
- No verb Review items in 0.5.0 (0.5.1).

## Other behaviour to mirror (Compose)
- Tab "Grammar" / "Gramática", fifth tab between Words and Settings (a lightbulb icon).
- Try it: the rule is hidden until the first pretest answer or Skip; later 3 items (never seen or missed first; items above the rule's level never drawn); at most 2 rounds (6 items) a rule a day, then "You've finished today's practice for this rule. Try another rule, or come back tomorrow." with "See other rules"; immediate feedback with icon and words, in the rule-text language; after a right answer only the chosen option is explained ("Why not the others?" one tap away); "Not sure" counts as wrong ("That's okay. Right: ..."). A repeat after a miss comes at least 3 cards later.
- The Spanish line heading is "If you speak Spanish" / "Si hablas español". Buttons are "Try it" the first time, then "Practice".
- "In your books" is not shown in 0.5.0 and nothing stands in its place. No streaks, no percentages, no message about missed days. Fully offline (everything bundled).
