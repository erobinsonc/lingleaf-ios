# Originality and similarity log: 18 graded stories (16 main + 2 kids)

Date: 2026-10-28. Checked by: Claude (subagent). The stories were not edited.

## Method

- Tool: WebSearch in standard mode only. Exact phrases were put in double quotes. Extended mode was not needed, because no search came back as an ambiguous partial match that needed a deeper look.
- For each story I searched the title (as a book, film, song or story), 4–7 distinctive sentences or phrases from the text, and a plain-language description of the premise (character + setting + plot hook). Where the story names a company or a person, I also searched that name.
- "0" below means the exact phrase appeared on no indexed page. The search engine's paraphrase hits on generic topics are not counted as matches.
- I also checked for named or imitated real brands, companies, songs, films and living people.

## Limits: what could not be checked

- **WebFetch could not reach any page.** Every host returned "ENOTFOUND / outside the session's allowed network domains": learnenglishteens.britishcouncil.org, lds.org, cerealreaders.com, badger.affinityagency.co.uk, fabulang.com. I stopped trying after these. **All evidence below comes from search-result snippets and titles. I did not read any full page.** To compare full texts, those hosts must be allowed in the session's network settings.
- A web search cannot see text that is not indexed: paywalled graded-reader catalogues (Oxford Bookworms, Penguin/Pearson Readers, Cambridge English Readers, Macmillan, Helbling, Black Cat), coursebooks, Kindle-only books and LLM training corpora. A clean result is evidence, not proof, that the text is original.
- I ran one exit search per story. The longer stories (B2, C1, C2) got 5–7 phrase checks each, so a reused paragraph in an unsearched part could be missed. Paraphrased (non-verbatim) borrowing is only partly covered, by the premise searches.
- A 5-hour usage limit paused the work after the B1 stories. The B2–C2 searches ran after it reset. Nothing was skipped.
